## 4. Công Cụ Vệ Sinh Dữ Liệu `scripts/maintenance/clean_runs.py` (Mục 4)

- **Vị trí tệp:** `scripts/maintenance/clean_runs.py`
- **Tính năng nổi bật:**
  1. **An toàn tối đa (Safe by Default):** Nếu người dùng không chỉ định `--trash` hoặc `--delete`, script tự động ép về chế độ `--dry-run`.
  2. **Bảo vệ bất biến:** Tự động bỏ qua `.gitkeep`, `spend.json`, các thư mục hàng đợi (`events`, `render_queue`, `_node_outputs`, `_voice_lines`) và các run được tạo trong vòng 2 giờ qua (`--keep-recent-hours 2.0`).
  3. **Hỗ trợ Thùng rác macOS (`--trash`):** Gọi lệnh AppleScript Finder chuyển file vào Thùng rác tương ứng của phân vùng ổ đĩa (khôi phục được).
  4. **Lọc thông minh:** Tự đọc `state.json` để nhận diện các node ID do test sinh ra (`node_idea`, `node_video_gen`, `test_*`, `mock_*`, v.v.).
- **Kiểm thử tự động:**
  - Đã viết bộ test: `tool/tests/test_clean_runs.py` gồm 6 test cases:
    - `test_get_dir_stats`: Kiểm tra thống kê tệp và dung lượng.
    - `test_analyze_run_dir_empty`: Nhận diện thư mục rỗng.
    - `test_analyze_run_dir_recent_protection`: Kiểm tra cơ chế bảo vệ run vừa tạo.
    - `test_analyze_run_dir_system_queue`: Bảo vệ hàng đợi hệ thống.
    - `test_analyze_run_dir_state_only_test`: Nhận diện run chỉ có `state.json` lỗi/test.
    - `test_analyze_run_dir_media_run_protection`: Bảo vệ run có media trừ khi có cờ `--include-media`.
  - Kết quả chạy test: `.venv/bin/pytest tool/tests/test_clean_runs.py` → **6 passed in 0.02s**.

## 5. Chốt Chính Sách Dữ Liệu Git & Cập Nhật `.gitignore` (Mục 2 & 5)

### 5.1. Chính sách cốt lõi

1. **Kho giọng đọc (`data/shared/voice_vault/**`):**
   - **Tài sản riêng tư / Cá nhân:** Chứa các mẫu giọng clone từ người thật (`.wav`, `.mp3`), file transcript gốc và cache mô hình OmniVoice (`.pt`, `.npy`).
   - **Chính sách:** **TUYỆT ĐỐI KHÔNG ĐƯA LÊN REPO CÔNG KHAI**. `.gitignore` đã chặn toàn bộ `data/shared/voice_vault/*` (chỉ giữ file giữ chỗ `.gitkeep`).
2. **Assets sinh tự động (`data/projects/*/assets/*`):**
   - **Bản chất:** Hàng ngàn file cache giọng đọc TTS mã băm sha256 (`.mp3`), phụ đề (`.srt`) và metadata (`.meta.json`).
   - **Chính sách:** Không commit lên Git vì có thể tự động tái tạo từ kịch bản bất kỳ lúc nào. `.gitignore` đã chặn toàn bộ `data/projects/*/assets/*` (trừ `.gitkeep`).
3. **Dữ liệu thô & rác tạm (`data/projects/*/raw/*`):**
   - **Chính sách:** Đã bổ sung vào `.gitignore` để chặn thư mục `_trash/` và video nguồn thô.
4. **Lịch sử chạy máy (`data/projects/*/runs/*`):**
   - **Chính sách:** Chặn toàn bộ, chỉ giữ `.gitkeep` và file sổ cái chi phí ngân sách `spend.json`.
5. **Dữ liệu chuẩn bắt buộc lưu trên Git:**
   - Nhân vật Master DNA: `data/projects/*/characters/**` (ảnh gốc, scale lock).
   - Kịch bản & Nội dung: `data/projects/*/content/**` (kịch bản 51 tập, prompts).
   - Tri thức video thực chiến: `data/shared/knowledge/**` (26 thẻ techniques, 7 playbooks).
   - Cấu hình dự án: `data/workspace.json`, `project.json`, `graph.json`, `policy.json`.
   - Templates & Brand kits: `data/shared/templates/**`, `data/shared/brand_kits/**`.

### 5.2. Hiệu quả tức thì trên `.gitignore`:
- Trước khi sửa: `git status` báo 30 thư mục giọng đọc `vn-*` và nhiều thư mục rác `raw/_trash/` chưa được theo dõi.

- Tệp `data/projects/soc-nho-tv/runs/spend.json` được nhận diện chính xác để theo dõi ngân sách SpendGuard.

- Trong commit trước đó (`a47479a`), có 611 file assets mã băm, 30 file voice_vault và 69 file raw đã bị commit vào Git.
